# 包装成本分析:不同包装材料的综合成本对比

用 Python(pandas + matplotlib)分析快递包裹数据,比较纸箱、木箱、气泡膜三种包装材料的**综合成本**,并给出可执行的优化建议。

## 项目背景

电商物流中,包装材料的选择直接影响两笔成本:**运费**(重量、体积)和**破损赔偿**。只看运费做决策容易失误,本项目把两者合并成"总成本"统一比较。

## 数据说明

`data/packages.csv` 共 15 条模拟订单记录,字段如下:

| 字段 | 含义 |
| --- | --- |
| order_id | 订单编号 |
| category | 商品类别(electronics / glass / ceramics / clothing) |
| weight_kg | 包裹重量(kg) |
| length_cm / width_cm / height_cm | 包裹尺寸(cm) |
| material | 包装材料(cardboard / wood / bubble) |
| freight_cost | 运费(元) |
| damaged | 是否破损(1 = 破损,0 = 完好) |

商品货值为假设值(电子 100 元、玻璃 150 元、陶瓷 100 元、服装 30 元)。

## 分析方法

核心公式:

```
总成本 = 平均运费 + 破损率 × 平均货值
```

其中"破损率 × 货值"是每件商品分摊到的预期破损损失。公式用 pandas 的 `groupby` 实现,详见 `analysis.py`。

## 核心发现

| 包装材料 | 平均运费 | 破损率 | 破损损失 | 总成本 |
| --- | --- | --- | --- | --- |
| bubble(气泡膜) | 5.75 | 0% | 0.00 | 5.75 |
| cardboard(纸箱) | 15.00 | 0% | 0.00 | 15.00 |
| wood(木箱) | 20.25 | 67% | 83.33 | 103.58 |

1. 木箱总成本是纸箱的 **6.9 倍**,但贵的不是运费(仅高 5.25 元),而是**破损损失占了木箱总成本的 80%**。
2. 木箱装的都是玻璃、陶瓷这类**高价易碎品**,破损率高达 67%,因此破损赔偿成为主要成本。
3. 换用纸箱每件可省 5.25 元运费;按玻璃平均货值 150 元计算,只要纸箱的破损率比木箱**上升不超过 3.5 个百分点**,换料就是划算的。

图表见 `charts/`:

- `cost_compare.png`:三种材料总成本对比
- `cost_stack.png`:成本构成(运费 + 破损损失)

## 优化建议

先小批量试运"纸箱 + 缓冲材料"包装玻璃陶瓷,采集真实破损数据;若破损率上升幅度小于 3.5 个百分点,则全面替换木箱方案,否则保留木箱并优化内部缓冲设计。

## 局限说明

本数据为教学用模拟数据,破损率偏高;真实快递破损率通常在 1%-3%。项目价值在于**分析框架**(总成本 = 运费 + 破损损失)与决策方法,而非具体数值。
